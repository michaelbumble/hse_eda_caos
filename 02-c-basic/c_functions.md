# Функции C для домашки `c_basic`

Короткая справка по функциям, которые используются в текущем наборе задач.

| Функция | Заголовок | Где нужна |
|---|---|---|
| `printf` | `<stdio.h>` | вывод в консоль |
| `scanf` | `<stdio.h>` | ввод из консоли |
| `getchar` | `<stdio.h>` | посимвольное считывание из консоли |
| `isdigit` | `<ctype.h>` | проверка что char - цифра |
| `ferror` | `<stdio.h>` | проверка ошибки потока |
| `strcmp` | `<string.h>` | сравнение двух C-строк |
| `strlen` | `<string.h>` | длина C-строки |

## `printf`

```c
int printf(const char *format, ...);
```

Выводит данные по формату.

```c
printf("%u\n", value);
printf("%zu\n", length);
printf("%c\n", character);
printf("%d\n", number);
```

Полезные спецификаторы:

- `%d` — `int`;
- `%u` — `unsigned`;
- `%ld` — `long`;
- `%zu` — `size_t`;
- `%c` — символ;
- `%s` — C-строка;
- `%f` — `double` / `float` после повышения аргумента;
- `%%` — символ `%`.

Функция возвращает количество выведенных символов или отрицательное значение при ошибке. В `average` ошибку вывода нужно обработать:

```c
if (printf("%u\n", answer) < 0) {
    return 1;
}
```

## `scanf`

```c
int scanf(const char *format, ...);
```

Читает данные по формату. Для изменяемых переменных передаёт адрес:

```c
unsigned a, b;

if (scanf("%u%u", &a, &b) != 2) {
    return 1;
}
```

Возвращает количество успешно прочитанных элементов или `EOF`, если ввод закончился до первого успешного чтения.

- `%u` — `unsigned`;
- `%d` — `int`;
- `%ld` — `long`;
- `%zu` — `size_t`;
- `%f` — `float`;
- `%lf` — `double`.

## `getchar`

```c
int getchar(void);
```

Читает один байт из `stdin`.

Возвращает:

- значение очередного байта как `unsigned char`, преобразованное к `int`;
- `EOF` (значение означающее "end of file") при конце ввода или ошибке.
- Чтобы самому в консоли завершить ввод, надо нажать Ctrl + D, тогда приложение получит EOF.

Результат храни в `int`, а не в `char`:

```c
int c;

while ((c = getchar()) != EOF) {
    /* обработка c */
}
```
## `isdigit`

```c
int isdigit(int c);
```

Проверяет, является ли символ десятичной цифрой.

```c
if (isdigit(c)) {
    sum += c - '0';
}
```

Возвращает ненулевое значение для цифры и 0 иначе. `c - '0'` превращает символ `'7'` в число `7`.

Если символ пришёл из `getchar`, передавать его напрямую безопасно. Для обычного `char` используй:

```c
isdigit((unsigned char)c);
```

## `ferror`

```c
int ferror(FILE *stream);
```

Проверяет, была ли ошибка при работе с потоком.

```c
if (ferror(stdin)) {
    return 1;
}
```

Полезна после цикла `getchar`, чтобы отличить конец файла от ошибки чтения.

## `strcmp`

```c
int strcmp(const char *s1, const char *s2);
```

Сравнивает две C-строки:

- 0 — строки равны;
- отрицательное значение — `s1` меньше;
- положительное значение — `s1` больше.

Гарантирован только **знак** результата, а не конкретные `-1` и `1`.

```c
int result = strcmp("a", "b");  /* < 0 */
```

## `strlen`

```c
size_t strlen(const char *s);
```

Возвращает длину C-строки до первого `\0`, не считая сам `\0`.

```c
char s[] = "abc";
strlen(s);  /* 3 */
sizeof(s);  /* 4, потому что массив содержит ещё '\0' */
```

Время работы — O(n). Если строка не заканчивается `\0`, вызов приводит к UB.

Подробнее: `man 3 printf`, `man 3 scanf`, `man 3 getchar`, `man 3 isdigit`, `man 3 strcmp`, `man 3 strlen`.
